# 로그 수집과 샘플 WAS

2026-11-03 기능별 문서 안내. 기존 원본을 옮기거나 복사하지 않고 필요한 부분으로 연결한다.

## 먼저 이해할 흐름

WAS가 자기 파일에 로그를 남기고, 별도 Vector가 파일을 읽어 중앙 API로 전송한다. WAS마다 파일과 수집기를 분리해 서버를 구분하고 재시작을 독립적으로 다룬다.

## 왜 이렇게 구성했나

Vector는 100건·크기·대기 시간 조건으로 묶어 보낸다. eventId는 묶음이 아니라 로그 한 건의 ID다. 체크포인트는 파일 처리 위치를 기록하며 재전송 가능성은 서버 중복 판정으로 다룬다. 유한 재시도와 파일 보존 때문에 모든 장애의 무손실을 보장하지 않는다. Kafka는 현재 두 WAS 데모에 추가 운영 부담을 넣지 않고 후속 검토로 남겼다.
