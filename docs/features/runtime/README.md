# 실행·검증·운영 준비

2026-11-03 기능별 문서 안내. 기존 원본을 옮기거나 복사하지 않고 필요한 부분으로 연결한다.

## 먼저 이해할 흐름

Compose는 DB·ES·백엔드·프론트·샘플·Vector를 함께 실행할 환경을 만든다. Testcontainers와 격리 Docker 검증은 실제 MySQL/ES와 브라우저 흐름을 확인한다.

## 왜 이렇게 구성했나

단위 테스트와 실제 DB/HTTP/브라우저 통합 검증은 서로 확인하는 문제가 다르다. 검증은 공통 verify.sh로 수행한다. 로컬 기능 검증 통과는 운영 인증·TLS·HA·부하 보장을 의미하지 않는다. 실제 배포는 별도 승인 후 진행한다.
